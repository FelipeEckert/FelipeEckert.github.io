# Felipe Arthur Eckert | Portfolio Home

Modern GitHub Pages-ready portfolio for Felipe Arthur Eckert, focused on Data
Analytics, Automation Engineering, Python tooling, and automotive data.

## Repository Type

This workspace was empty and not initialized as a git repository, so it has been
set up as a lightweight static portfolio site. It can be published directly with
GitHub Pages from the repository root.

## What Is Included

- `index.html`: semantic landing page with hero, about, featured work, tech
  stack, current focus, and contact sections.
- `styles.css`: responsive visual system with clean spacing, cards, and a
  professional data/automation look.
- `script.js`: lightweight canvas animation for a vehicle-data hero background.

## Local Preview

Open `index.html` directly in a browser, or run a tiny static server from this
folder:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Publishing With GitHub Pages

1. Push this branch to GitHub.
2. Open the repository settings on GitHub.
3. Go to **Pages**.
4. Set the source to **Deploy from a branch**.
5. Select the branch and `/ (root)` as the publishing folder.
